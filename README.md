## 📌 Descripción del Proyecto

**SistemaProduccionGanadera** es una solución tecnológica desarrollada para la digitalización y optimización operativa de fincas ganaderas. El sistema centraliza la trazabilidad individual del hato bovino, permitiendo monitorear los ciclos reproductivos, la producción láctea y la evolución del peso de los animales para la toma de decisiones basada en datos.

---

## 🚀 Módulos del Sistema

| Módulo | Características Principales |
| :--- | :--- |
| 🧬 **Gestión Reproductiva** | Control de celos, registro de inseminaciones/montas, diagnóstico de gestación y proyección de partos. |
| 🥛 **Producción Láctea** | Monitoreo diario por ordeño, cálculo de promedios de litros/vaca y rendimiento histórico. |
| ⚖️ **Desarrollo Ponderal** | Historial de pesajes, cálculo de Ganancia Media Diaria (GMD) y curvas de crecimiento. |
| 📋 **Ficha y Trazabilidad** | Hoja de vida por bovino (chapa/crotal), genealogía, categoría (terneros, novillos, vacas, toros) y sanidad. |
| 📊 **Analítica y Reportes** | Indicadores de productividad, tasa de natalidad y balance general del hato. |

## 🛠️ Arquitectura Tecnológica

* **Backend:** Framework Laravel (PHP 8.2+)
* **Frontend:** Blade, Tailwind CSS / Bootstrap, JavaScript
* **Base de Datos:** MySQL / PostgreSQL / SQLite
* **Servidor Local:** Apache / Nginx (Laragon / XAMPP)

---

## ⚙️ Requisitos del Sistema

* PHP >= 8.2 (Extensiones: `pdo`, `mbstring`, `openssl`, `tokenizer`, `xml`)
* Composer >= 2.x
* Node.js >= 18.x & NPM
* Motor de base de datos relacional
